# Lingo Translate

跨应用的中英文日文划词翻译工具。

## 当前版本

### Windows 桌面版

在任意 Windows 应用中选中文字并按 `Ctrl+C`，桌面版会自动识别中文、英文或日文，并在屏幕右上角显示译文。

- 英文 / 日文 → 中文
- 中文 → 英文（默认）或日文
- 浏览器前台时可交给浏览器扩展处理，避免两个悬浮窗冲突
- 自动忽略文件路径、网址和网络路径
- 单实例运行

运行文件：[outputs/lingo-lens-desktop/LingoLensDesktop.exe](outputs/lingo-lens-desktop/LingoLensDesktop.exe)

### 浏览器扩展

在网页中选中英文后自动在浏览器右上角显示中文翻译。

安装说明：[outputs/lingo-lens-extension/README.md](outputs/lingo-lens-extension/README.md)

扩展压缩包：[outputs/lingo-lens-extension-v0.1.0.zip](outputs/lingo-lens-extension-v0.1.0.zip)

## 注意事项

翻译服务使用公共接口。复制的文本会发送给对应翻译服务；处理敏感内容前请先确认服务的隐私政策。
