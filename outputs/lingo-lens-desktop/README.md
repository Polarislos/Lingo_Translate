# Lingo Lens Desktop

这是一个 Windows 桌面版划词翻译工具，适用于浏览器之外的大多数软件，例如 Word、PDF 阅读器、代码编辑器和聊天软件。它会自动判断剪贴板内容是中文、英文还是日文。

## 使用

1. 推荐直接双击 `LingoLensDesktop.exe`，不需要安装 Python。
2. 如果 Windows 弹出“未知发布者”提示，选择“更多信息”后再选择“仍要运行”。这是本地生成、未签名的个人工具。
3. 也可以使用 `启动 Lingo Lens.cmd` 启动源程序版。
4. 保持小窗口运行。
5. 根据需要选择“中文翻译为：英文 / 日文”。
6. 在任意软件中选中中文、英文或日文，按 `Ctrl+C`。
7. 英文和日文会自动译成中文；中文按你的选项译成英文或日文。结果显示在屏幕右上角，18 秒后自动收起。

## 为什么需要 Ctrl+C

Windows 没有一个稳定、安全的方式让普通应用直接读取每个软件内部的“当前高亮选区”。复制是跨应用通用的系统入口，因此这里把 `Ctrl+C` 作为自动翻译触发动作，不需要额外点击翻译按钮。

## 说明

- 不会上传你的浏览历史或文档内容。
- 只有你复制的、包含中文、英文或日文的文字会被送到翻译服务。
- 常见单词带有少量双向内置释义。中英方向使用 MyMemory 公共接口，涉及日文的方向使用 Google Translate 公共接口。
- 需要联网翻译较长句子。
- 默认在 Chrome、Edge、Firefox 等浏览器处于前台时暂停桌面剪贴板翻译，由网页扩展负责，避免两个翻译窗口重叠。
- 文件路径、网址和网络路径会自动忽略，不再当作英文句子翻译。
- 程序只允许同时运行一个实例，重复双击快捷方式不会产生第二个监听窗口。
- 含平假名或片假名的日文会自动识别；完全由汉字组成的短语会按中文处理，因为两者在字符层面无法可靠区分。
