# Lingo Lens 浏览器扩展

这是“划词即翻译”的 MVP：在英文网页中选中一段文字，松开鼠标后会自动在浏览器右上角显示中文悬浮卡片，无需再点击确认。

## 安装到 Chrome / Edge

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前这个 `lingo-lens-extension` 文件夹。
5. 打开任意英文网页，选中英文即可测试。

如果你在扩展管理页点击过“重新加载”，也需要刷新已经打开的网页一次，浏览器才能注入新版划词脚本。

## 当前能力

- 选中英文后自动翻译，无需再点击
- 中文结果固定显示在浏览器右上角，不遮住选区
- 支持复制原文和译文
- 支持收藏到本机浏览器
- 内置几个常见词的离线释义
- 默认通过 MyMemory 公开接口处理其他文本
- 可在扩展详情页的“扩展程序选项”中更换翻译服务地址

这是一个本地 MVP，未发布到商店，也不会自动上传浏览历史。真正长期使用时，建议将公开翻译接口换成自己的后端或明确配置的翻译服务。
